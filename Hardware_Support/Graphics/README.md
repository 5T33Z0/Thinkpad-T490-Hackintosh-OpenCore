# Intel UHD 620 Framebuffer Patches

- The .plist contains some working fb patches
- The **VBT.bin** (Video BIOS Table) contains the actual physcial output routing of the iGPU. You can import it into [**vbt2fbpatch**](https://github.com/5T33Z0/vbt2fbpatch/tree/main) and build your own FB patch for your Lenovo T490.
